This page is the **documentation site** 404. It is not an HTTP response from a Flare app.

In a running Flare app, when no registered route matches the request path, Flare returns status **404** with a plain-text body `"Not Found"` and `Content-Type: text/plain`. That is the default before you register a catch-all route.

When the path matches a route but the HTTP method has no handler, Flare returns **405 Method Not Allowed** instead. Unmatched paths are not handled by `host.http.error()`. Path matching, method dispatch, and custom 404 handling (for example a wildcard catch-all such as `host.http.get("/*path", …)`) are documented in [Routing reference](/core/http/routing-reference/#path-not-found-404).
