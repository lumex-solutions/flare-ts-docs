`@flare-ts/core` is Flare's framework package: the composition root (`FlareHost`), HTTP arc, dependency injection, config tokens, logger, and runtime adapters. For how these pieces fit together, see [Concepts](/concepts/). For schema primitives used in contracts and config, see [Lib](/lib/).

## Topics in this section

- **[Host](/core/host/)**: `FlareHost`, runtime adapters, `build()`, and the app lifecycle (`.run()`, `.export()`, `.test()`).
- **[HTTP](/core/http/)**: routing, controllers, middleware, request state, and contracts.
- **[Logger](/core/logger/)**: transports, log levels, and log config.
- **[Config](/core/config/)**: `flareConfig()` tokens, `flare.json`, and [`FLARE__*` environment overrides](/core/config/#environment-overrides).
- **[Testing](/core/testing/)**: `FLARE_MODE=test`, `app.test()`, and the test harness API.
- **[Errors](/core/errors/)**: `FlareError`, `flareErrorCodes`, categories, and error-schema typing.
- **[Failure modes](/core/failure-modes/)**: when errors surface during composition, build, startup, and request handling.
